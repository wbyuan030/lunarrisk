# P2.2 P22-02 — H1/H2 统计验收与止损决定（2026-10-23）

**结论：`STOP_OR_REFRAME`。**
在修正后的评分口径、统一样本集与组级配对区间下，**H1 被否决，H2 不成立**：
没有任何证据表明 diag（P2）或 rank-2 联合后验（P3）能稳定超过点估计模型；
联合模型唯一稳定可归因的效果是 **off-diagonal 相关性对 `g15` 事件概率有害**，
而这一效应不足以让联合模型反超点模型。

## 1. 假设与判定标准

- **P1 = point**：共享 encoder + 4 输出，Train 残差高斯（Cal-T 缩放）。
- **P2 = diagonal**：每个属性独立的 μ、σ（Cal-T）。
- **P3 = joint**：`Σ = diag(σ²) + UUᵀ`（rank 2，Cal-T）。
- **H1**：P2 优于 P1（属性条件分布比点估计更有用）。
- **H2**：P3 优于 P2（跨属性相关性再带来增益）。

判定标准（P2.2 预注册）：在相同 sample ID、相同规则、相同 Cal-T 口径下，
ΔBrier / ΔNLL 的 **25 组 paired bootstrap 95% CI** 在 **3 个 seed 中至少 2 个**
同向且不跨 0，并同时不劣于 `coarse_ridge` 与 `direct_event`。达不到即 `STOP_OR_REFRAME`。

## 2. 证据摘要

### H1（P2 > P1）：否决

| 规则 | diagonal − point（seed 42/43/44，ΔBrier；* = 95% CI 不跨 0） |
|---|---|
| `g10>0.05` | +0.0206 / −0.0086 / **+0.0326\***（2 个 SIG，方向为 diagonal **更差**） |
| `g15>0.02` | **+0.0259\*** / −0.0097 / **+0.0510\***（diagonal 更差） |
| OR | +0.0148 / −0.0012 / **+0.0411\*** |
| AND(rough) | **−0.0289\*** / **−0.0616\*** / +0.0009（diagonal **更好**） |
| NOT | **−0.0299\*** / **−0.0454\*** / +0.0130（diagonal **更好**） |

- 整体均值：point Brier 0.0747（g10）、0.0781（OR）；diagonal 0.0896、0.0963。
- diagonal 只在含 roughness 的 AND / NOT 规则上占优，这不支持“多属性条件分布整体更好”，
  而是说明**点模型对 roughness/relief 的残差几何（对数链 + 残差高斯）标度不佳**，
  与“需要跨属性相关性”是两件事。
- diagonal 在所有 seed、所有主要规则上都劣于 `direct_event` 或与之相当，
  同时只在部分规则上优于 `coarse_ridge`。
  → **H1 否决**：diagonal 后验不是比点估计更好的默认选择。

### H2（P3 > P2）：不成立（符号随 seed 翻转）

| 规则 | joint − diagonal（seed 42/43/44，ΔBrier；* = CI 不跨 0） |
|---|---|
| `g10>0.05` | **−0.0254\* / +0.0277\* / −0.0137\***（显著但方向相反） |
| `g15>0.02` | **−0.0157\* / +0.0489\* / −0.0173\***（同上） |
| OR | −0.0137 / **+0.0294\*** / **−0.0130\*** |
| AND(rough) | +0.0066 / **+0.0604\*** / −0.0027 |
| NOT | −0.0228 / **+0.0499\*** / −0.0053 |

- 3 个 seed 的 CI 几乎都显著，但**方向不一致**；这正是“训练不稳定”而不是“模型更好”。
  按预注册标准，不能宣称 H2 成立。
- joint 相对 point：`g15` 为 +0.0102 / +0.0392\* / +0.0337\*，`g10` 为
  −0.0048 / +0.0191\* / +0.0189\*（正 = joint 更差），OR 规则为 +0.0011 / +0.0281\* / +0.0280\*，
  NLL 同向更差。**joint 没有超过最简单的点模型。**
- `direct_event` 在 `g10` 与 point 无显著差异；在 `g15` 上均值更好（0.0880 vs 0.0925），
  但 seed 间波动大（0.0586–0.1001），不能作为稳定基线。

### 相关性到底有没有用？（同 checkpoint 消融）

用 **matched-marginals**（保留 `diag(Σ_joint)`，仅去 off-diagonal）在 `g15>0.02` 上对比完整 joint：

| seed | matched − joint（ΔBrier） |
|---|---|
| 42 | −0.0066 [−0.0124, +0.0010] |
| 43 | **−0.0117 [−0.0177, −0.0046]** |
| 44 | **−0.0096 [−0.0150, −0.0028]** |

**去掉 off-diagonal 相关性会稳定改善 `g15` 事件概率**，同时 `P(g10>t)` 因 Cholesky 结构
严格不变（Δ=0）。这是目前唯一可归因的“相关性效应”，方向是 **学到的相关性有害**。
但注意：joint 本来就比 point 差 ~0.028，去相关只回收 ~0.01，仍明显不如 point。
`U=0` 的更大“改善”同时缩小边缘方差，且随 `shared_T / refit_T` 口径变化很大，
不能单独作为相关性证据。

## 3. 判定

| 假设 | 结果 | 理由 |
|---|---|---|
| H1（P2 > P1） | **REJECTED** | 方向不一致；仅含 roughness 的规则占优；整体劣于 point |
| H2（P3 > P2） | **NOT ESTABLISHED** | 3 seed 间符号翻转；不满足“2/3 同向”标准 |
| 联合 > point | **REJECTED** | `g15` 3/3、`g10` 2/3 显著更差，NLL 同向更差 |
| 联合 > ridge | 部分 | g10 2/3 显著更好，但只是回到 point 已能达到的水平 |
| 联合 > direct_event | 否 | g10 无差异，g15 差，seed 波动大 |

**决定：`STOP_OR_REFRAME`。** 按 P2.2 的止损条件，不再为获得正结果而添加
LFM / One-Pass / JEPA / LLM，也不在 `development_test` 上继续挑选规则、阈值或架构。

## 4. 这个结论不意味着什么

- **不代表**协调方差建模在月球地形上普遍无用；本轮只有 399 个训练 Tile、
  rank-2、单一 encoder、单任务四属性，且目标是从 3 m DTM 派生的工程代理。
- **不代表**外部 OOD 结论；全部结果仍是反复查看的 110 Tile 开发集。
  Gate 3 `NOT_FROZEN`、Gate 4 `HOLD` 不变，未在外部场景上训练、调参或预测。
- **不代表**点模型已经可用于着陆安全认证；它只是当前数据与规则下最稳的**工程代理**。

## 5. 建议的下一步（不引入新大模型）

1. **把 point + 残差高斯（Cal-T）设为新的参考模型**，所有后续比较以它为基准，
   并要求 `direct_event` 在同一规则集上重新训练（当前它只覆盖 2 条规则）。
2. **先修 roughness/relief 的边缘分布**：AND/NOT 规则上 diagonal/ridge 更好，说明
   对数链 + 高斯残差对米制长度的尾部不合适；可考虑显式的正长度分布或分位数回归，
   这是“分布假设”问题，不是“相关性”问题。
3. **相关性只在跨属性事件上有意义**：若继续联合建模，评价指标必须包含
   `matched-marginals` 对照，并预先说明 `g10` 单属性规则在结构上不可用于归因。
4. **外部 heldout 仍按原计划**：先完成 v2 协议签核与 Gate 3 QA，再一次性评估；
   在此之前不再用开发集挑选任何模型。
