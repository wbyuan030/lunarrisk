2026-11-07. **The currently served official LOLA GeoTIFF declares NoData −32768**, signed 16-bit samples and scale 0.5. The configured SLDEM PDS label contains no explicit NULL, MISSING, INVALID or SPECIAL keyword. These observations narrow the source investigation; they do **not** establish the exact files or intermediates used to build the retained Moonstone cohort, nor prove the runner's `finite_only_no_finite_sentinels` assertion.

The fixed Moonstone config names the [USGS LOLA GeoTIFF](https://planetarymaps.usgs.gov/mosaic/Lunar_LRO_LOLA_Global_LDEM_118m_Mar2014.tif). Direct no-proxy HTTPS returned a USGS redirect to its S3 object. A bounded 1 MiB request returned HTTP 206 with the requested Content-Range out of 8,494,203,833 bytes. Existing `tifffile` parsed the TIFF directory without reading image pixels: 92,160 × 46,080, signed int16, GDAL NoData −32768, scale 0.5, offset 0. The [USGS product description](https://astrogeology.usgs.gov/search/map/moon_lro_lola_dem_118m) independently describes the scale and interpolated gaps. The multipart ETag and range SHA identify the currently observed response, not the full-file SHA or historical build input.

The directly retrieved [SLDEM label](https://imbrium.mit.edu/DATA/SLDEM2015/GLOBAL/FLOAT_IMG/SLDEM2015_128_60S_60N_000_360_FLOAT.LBL) is 4,588 bytes and describes a 15,360 × 46,080 32-bit floating image in kilometres, with declared height extrema −8.717 to 10.778 km. No explicit NULL, MISSING, INVALID or SPECIAL keyword appears in that label. That absence does not establish how the image or its conversion handles all special values. The IMG itself was not downloaded or inspected.

The pinned source masks `src.nodata` before multiplying the original values, then reprojects and blends; it can also reuse existing converted, scaled, aligned and blended intermediates. The scaling routine copies the input profile without explicitly changing its NoData metadata to NaN, even though it writes masked pixels as NaN. The subsequent reprojection passes the scaled file's declared `src.nodata` to GDAL. The actual intermediate metadata, GDAL behavior and build versions are not established, so this code alone does not prove how every NaN was handled. If an unmasked LOLA −32768 were scaled by 0.5, its direct value would be −16384 m. The completed cohort diagnostic's elevation minimum is above this, so that exact output value is absent. Interpolation or blending could change a bad input's value, however, and the actual source headers, intermediate identities and run logs were not independently recovered. This observation cannot justify a complete source-validity claim.
